## 확인한 문제와 변경

- 학생 자동 조회는 고정 `setInterval`이었다. 3.9초 걸리는 조회가 끝나도 4.4초 시점에 다음 조회가 시작됐다. 완료 이후 기기별 대기 간격을 두는 `setTimeout`으로 변경했다. 숨김·오프라인 검사, 실패 시 기존 backoff, 포커스 중복 방지와 화면 이탈 시 해제를 유지한다. 수동 조회 및 저장 후 갱신의 성공 판정은 변경하지 않았다.
- `storage_load_scope`의 `DISTINCT r.*`는 JSON을 포함한 전체 행을 정렬했다. PK 기반 `EXISTS`로 선택하여 중복과 정렬을 없앴다. 기존 데이터 선택 조건, 권한, 영수증, revision, 삭제 기록 및 배열 순서 정보는 유지한다.
- 새 SQL: `supabase/storage_scope_read_performance.sql`. 기존 scoped schema와 read performance SQL 이후 실행하는 독립 migration이다. **사용자 승인 후 2026-09-15 운영 적용 완료**.
