# 2026-09-28 저장 오류 조사

## 확인한 운영 증거

- 대상: School_Timer Supabase 프로젝트와 `school-timer-five.vercel.app`.
- 읽기 전용 SQL과 로그 집계만 사용. 학생 작성 내용·인증정보는 수집하지 않음.
- 00:25–01:35 UTC 로그에서 statement_timeout(57014) 17건. 그중 16건이 01:27:12–01:28:02 UTC에 집중했고 `storage_load_scope`와 `storage_load_snapshot`에서 발생.
- 같은 구간의 낱말판 조회 및 보상 RPC도 최대 6–8초로 지연. 해당 시간대의 보상 RPC HTTP 상태는 200이었음. 이것만으로 개별 브라우저 요청의 도달·응답 수신 여부는 확정할 수 없음.
- 00:35 UTC 오프라인 오류를 보고한 학생의 신문 질문 주간 보상은 00:34:08 UTC 지급 기록이 있음. 오류 알림을 보상 미지급으로 해석해서는 안 됨.
- 조회 구간에서 `storage_load_scope_metadata` 호출은 0회. Vercel 프로젝트의 Project·Shared 변수 탭에서 모든 환경 대상으로 `STORAGE_SCOPED_POLLING` 검색 결과가 없는 것을 직접 확인. `STORAGE_PROTOCOL_VERSION=2`는 사용자가 첨부한 운영 설정 화면에서 확인.
- Vercel 첫 접근은 `ERR_CERT_COMMON_NAME_INVALID`로 차단되었으나 프로젝트 설정 직접 주소로 재접속하여 정상 접근. 인증서 검증 우회 없음.
- Vercel 최근 한 시간 `/api/weekly-missions` 로그에서 10:27:20.39, 10:27:33.84, 10:27:36.96 KST 요청의 warning 확인. 각각 `classword_word_entry`(elapsedMs 26149), `personal_question`(12058), `classword-reward-ledger`(8004) 단계에서 `TimeoutError`, `WEEKLY_MISSIONS_UPSTREAM_FAILED` 기록. 요청 목록의 HTTP 상태는 200. 해당 로그가 특정 학생의 TypeError 요청과 동일한지는 확인 불가.

## 가설과 검증

1. 낱말판은 3초마다 이전 응답과 무관하게 다음 조회를 시작한다. 실제 컴포넌트의 조회·effect 코드를 실행하고 8초 응답 지연 및 focus/visibility 이벤트를 주입했을 때 endpoint별 미완료 요청 5개를 재현. 수정 후 1개이며 정상 응답을 화면 상태에 적용한다.
2. 학생별 변경 확인 flag 누락을 확인. 기존 API 테스트는 누락 시 전역 수정시각 RPC로 돌아가는 동작을 검증하며 클라이언트 테스트는 개인 readVersion 불변 시 전역 수정시각이 달라도 전체 재조회를 하지 않는 동작을 검증한다.
3. DB 지연과 브라우저 TypeError의 직접 인과관계, 학교 네트워크 장애 여부는 Vercel 요청 로그 없이 확정하지 않는다.

운영 SQL에는 9월 21일 범위 조회 최적화가 이미 적용되어 있다. 동일 마이그레이션을 반복하거나 학생 기록을 수정하지 않는다.

## 수정 및 적용 조건

- `StudentClasswordPage.tsx`: 낱말판·퀴즈 조회가 모두 끝난 뒤 3초 후 폴링. 진행 중 포커스 이벤트는 중복 요청을 만들지 않고, 저장 알림은 완료 후 한 번 새로 조회한다. 오프라인/숨김 중 요청 중지, online/화면 복귀 시 재개, 종료된 effect의 응답 적용 차단.
- `classwordPolling.test.ts`: 8초 지연, 저장 알림 병합, 화면 종료, 네트워크 실패 후 오프라인/화면 복귀를 실제 컴포넌트 코드로 검증. 수정 전 3개 실패, 수정 후 3개 통과. 추가한 오프라인 연습 모드 회귀까지 4개 통과.
- 사용자 승인 후 Vercel Production 환경에 `STORAGE_SCOPED_POLLING=1`을 Config 변수로 저장했다. 해당 SQL 함수는 이미 존재한다. `STORAGE_PROTOCOL_VERSION=2` 유지. 환경변수 변경은 새 배포부터 적용된다: https://vercel.com/docs/environment-variables
- 운영 배포 및 학생 브라우저 새 버전 적용 전에는 해결 완료로 판단하지 않는다. 배포 후 metadata RPC 호출 발생, 정상 학생 읽기, 학교 동시 사용 시 시간초과 감소를 확인해야 한다.
