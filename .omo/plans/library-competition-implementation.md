# 전국 책방 챌린지 구현

승인 범위: 제공한 17개 학교, 실제 배치 0~100권, 월별 결정적 경쟁, 원자적 보관/초기화, 교사 설정, 도서관 순위판.
운영 DB SQL 적용 및 Git 커밋/푸시는 포함하지 않는다. 기존 변경사항을 보존한다.

## 진행
- [x] 순수 계산 모델과 시드·시간·교사 조정 재현 테스트
- [x] 서버 명령·원자적 저장·월별 보관 SQL·권한/경쟁 테스트 (운영 SQL 미적용)
- [x] 격리 로컬/공유 클라이언트·배치 시즌·갱신 연결
- [x] 학생 순위판·지난 기록·교사 설정·동선
- [x] 타입 검사·전체 테스트 669개·빌드·1280×800 실제 플레이 90개 화면·독립 시각 검토 2건 통과

## 제약
- 운영 DB 미적용 시 새 경쟁 기능만 비활성화하고 기존 도서관 보존.
- QA는 연습 모드와 가짜 저장소만 사용. 새 QA 서버/브라우저 종료.
- 학생 표시에는 가상 안내를 넣지 않되 공식 통계/실시간 대출 연동을 주장하지 않는다.
- 운영 적용은 별도 승인 대기. PostgreSQL 실행 환경이 없어 SQL 엔진 수준 검증은 미실행이며 코드/HTTP fixture 검증과 구분한다.
- 최종 기록: `.omo/evidence/library-competition/implementation-report.md`. QA 브라우저/3044 서버 종료, 사용자3000 서버 유지.
