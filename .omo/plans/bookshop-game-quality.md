# 책방 게임 완성도 Goal

목표: 앞서 제안하고 사용자가 순차 반영을 요청한 공간·시점 → 조작 → 연출 개선 전체. 따뜻한 책방 정체성, 기존 기능, 100개 슬롯 ID와 저장 호환성을 유지한다. 기존 삭제 요청(입구 매트/흰 선/챌린지 footer)과 문 주변 자유 이동, 55% 문/28% 서가 표현을 유지한다.

## 1. 공간과 시점 — 진행 중
- [ ] 동일한 목재 윗면/앞면/측면 규칙을 서가, 등록대, 독서 가구, 진열대에 적용한다.
- [ ] 서가 상판의 깊이를 확보하고 실제 책 슬롯/책 그림/배치 도착점을 함께 조정한다.
- [ ] 바닥/벽 명암과 접촉 그림자를 정리해 가구·캐릭터의 가독성을 높인다.
- [ ] 0/30/100권 동일1280×800 전후 화면과 실제 주요 동선 영상을 검수한다.

## 2. 조작과 동작 — 대기
- [ ] 보행 시 발 고정/몸체 리듬, 방향 전환, 손과 도구 접촉을 다듬는다.
- [ ] 근접 E 대상의 흔들림을 줄이고 접근/중단/재개/충돌 동작을 검수한다.
- [ ] 모달, 창 비활성화, 동작 줄이기에서도 기능과 초점을 유지한다.

## 3. 연출과 생활감 — 대기
- [ ] 책 전달/배치를 준비→이동→정렬→완료 흐름으로 다듬는다.
- [ ] 직원의 바라보기/정리, 고양이의 휴식 장소 선택을 안정된 생활 리듬으로 개선한다.
- [ ] 광원별 빛과 효과의 강도/방향, 안내의 표시 전환을 정리한다.

## 최종 증거
- [ ] 공간/충돌/경로/자세/저장 호환성 회귀 검사
- [ ] 전체 npm test, npm run lint, npm run build
- [ ] 실제1280×800 스크롤/겹침/프레임시간·콘솔 확인
- [ ] 같은 장면의 전후 이미지, 조작 영상, DESIGN.md 계약 갱신
- [ ] 각 항목의 실제 파일·검증 로그·화면을 다시 감사하고 전체 완료가 입증될 때만 Goal 완료

첫 Goal 턴: 이전 아이디어 제안은 구현 전 단계. 이번 턴은 현재 작업 트리를 확인하고 1단계부터 진행한다.
