# 낱말 퀴즈 지급 보장 수정

기준 커밋: 8c565d6bf098d5e3b849ca562ba133b7f3150636; 변경 상태는 changes.patch 참조.

- 정답 완료 시 일별 지급 청구·양수 원장 금액·원장의 증감 일치를 DB가 검사한다.
- 지연 제약 트리거가 직접 INSERT/UPDATE로 미지급 완료를 저장하는 경로도 차단한다.
- 한도 초과 시 완료/지급/영수증을 함께 롤백한다. 같은 요청 ID 재시도 가능.
- 기존 요청 재생 때도 지급 증거를 검증한다. 보상 조회는 청구와 원장을 함께 확인하며, 미확인 기록은 완료 표시하지 않는다.
- 연습 모드는 기존 완료 키를 대기 기록으로 사용하고, 원장이 있을 때만 완료로 읽는다. 최초 금액 유지·중복 지급 방지.
- 오류 안내와 다시 시도 버튼, 공통 저장 오류 보고를 연결했다.

검증:
- 로컬 실제 PostgreSQL의 tests/storage/classword-concurrency.mjs 통과. 24개 동일/상이 요청 ID 각 한 번 지급, 동일 금액 유지.
- tests/storage/classword-v2.sql: 한도 초과 후 완료/원장/청구/영수증 없음, 같은 ID 복구 재시도, 원장 없는 청구 거절, 직접 미지급 완료 저장 거절.
- 전체 테스트·타입 검사·빌드 통과(첨부 로그).
- 실제 브라우저에서 합성 저장 실패 -> 재조회 후 미완료 -> 같은 답 재시도 -> 정답 6고마 / 잔액 106 -> 재조회 유지 확인. 브라우저 오류 로그 없음. 실제 학생 데이터 미사용.
