## 실제 조작

- 빈 방 `empty-autonomous.webm`:144초.100권 `full-autonomous.webm`:134.798703초. 둘 다 실제 Canvas624×376 녹화, 브라우저에서 재생 확인. 기록 중 위치 이동/휴식 전환을 확인했고 관통/순간이동 오류는 관찰되지 않음.
- 영상은 마지막 측면 쓰다듬기 접근 보정 전 촬영. 보정에서 접근 후보와 해당 후보가 없는2개 격자를 제외했으며, 보정 후 별도 실제 쓰다듬기 재검수: `pet-side-active.png`.
- 개발 미리보기로 look/walk/sit/sleep/groom/stretch/watch/yield/pet 및 네 방향 보행 확인: `pose-*.png`, `walk-*.png`.
- 곰이 왼쪽으로 접근: 곰(376,272)→(361.07,272), 고양이(346,272)→(339.9904,272). 충돌 전에 양보하고 곰이 멈추면 바라보기. 동적 대상은 bookshop-cat 유지.
- 실제 쓰다듬기 중 위치 고정, 완료 후 반응/쉬기 확인. E6회 연타 후 catReactions=1. 접근 중 곰이 고양이를 가리던 문제를 측면 접근으로 수정하고 시각 재검수.
- 창 비활성 이벤트 전후 고양이 JSON 완전히 동일. 활성화 후 재개.
- 등록 모달을 열어 제목/글쓴이를 입력하는 동안 고양이 JSON 완전히 동일. 닫은 후 재개.

## 증거 범위

`pet-active.png`는 수정 전 겹침을 발견한 기록이므로 완료 이미지로 사용하지 않음. 최종 쓰다듬기 증거는 `pet-side-active.png`. 기존 책 배치/가구 기능의 모든 경우를 새로 영상화한 것은 아니며 해당 회귀는 전체 테스트와 위 실제 접근 조작으로 확인함.
