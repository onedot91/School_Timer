# 교사 상단 UI와 보상 점검 표시

변경: 정상 상태의 보상 점검 트리거 숨김(폴링 유지), 미해결 보상/조회 오류/열린 대화상자는 유지. 정상 헤더 한 줄, 실제 경고는 두 줄. 일정 목록과 헤더 사이8px 간격. 수업 종료 후 첫 일정 표시. 자동 스크롤은 가능한 행 시작에 정렬하되 대상 일정이 잘리지 않는 범위 유지.

Before: 실제 localhost 교사 화면 헤더103px, 일정 목록이 헤더 경계에 붙음, scrollTop287.5.
After: 실제 localhost 1280×650/600/800에서 헤더57px, 날짜 비절단, 정상 보상 버튼 없음, scrollTop0, 문서 overflow없음. 650에서 설정 열기/닫기 정상.
설정·학생·고마 데이터 변경 없음. 로컬 UI 수정이며 이번 변경은 아직 운영 배포하지 않음.
