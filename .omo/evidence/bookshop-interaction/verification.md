# 다양한 방향 상호작용과 출입구 이동 · 2026-09-06

## 변경
- E 선택은 기존 접근점 28px 범위에 더해 가구 표시 영역 주변 18px까지 허용한다. 단일 대상은 특정 방향을 요구하지 않으며, 겹친 후보는 바라보는 방향과 거리로 결정한다.
- 생활 동작/직원 책 받기는 실제 발 충돌 크기로 구한 모서리 경유 경로를 따라 기존 동작 위치에 도달한다. 경로는 시작할 때 계산하며 가구와 고양이를 통과하지 않는다. 기존 도구 목표/최대12px 팔 길이는 유지한다.
- 동작 줄이기에서도 필수 접근을 수행한 뒤 동작을 즉시 완료한다. 모달/비활성화 중 경로 진행은 정지한다.
- 문은 곰/고양이 이동 장애물에서 제거한다. 문 그림은 그대로이며, 남쪽 이동 경계의 마지막2px에서 문 폭 안의 아래 방향 입력에만 기존 퇴장 모달을 연다.

## 검증
- 관련 world45개 통과. 통합 npm test773개 통과. npm run lint 및 npm run build 통과. git diff --check 통과.
- 읽기 전용 코드 감사에서 차단 이슈 없음.
- 실제 브라우저1280×800에서 등록대 왼쪽(174.70,298.70)에서 E로 등록창을 열고 예시 책을 요청했다. 가구와 고양이를 우회해(233,327)에서 책을 받았고 운반 상태가 표시됐다.
- 운반 중 문 그림 내부(332.91,327), 이어서(357.91,352)까지 막힘 없이 이동하고 모달이 없음을 확인했다.
- 더 아래로 걸어 남쪽 경계에 닿으면 운반 취소 퇴장 모달이 열렸다. 취소 후 책을 유지하고 Canvas application에 초점이 복귀했다.
- 경계(357.92,353.67)에서 왼쪽/오른쪽 왕복 후 모달이 다시 열리지 않았다.
- 자동 회귀에서 서가/등록대 앞뒤·양옆 선택, 생활 가구 여러 방향에서 실제 경로 이동, 막힌 경로 실패, 곰과 고양이 문 영역 양방향 통과, 정지/옆 이동 미발동을 확인했다.
- 전등 위쪽(580.94,214.64)에서 E를 누르면 기둥을 우회해(556.08,242.19), 오른쪽 자세로 조명을 끔(lampOn=false)을 확인했다.
- 최종 innerWidth/innerHeight 및 document scrollWidth/scrollHeight 모두1280/800. 콘솔 경고/오류 없음. 임시 뷰포트 설정 복원.
