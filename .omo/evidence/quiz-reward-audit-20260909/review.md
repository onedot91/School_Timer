## 확인한 문제

1. 보유 한도 999999에 도달하면 완료는 저장되지만 보상 청구가 생성되지 않는다. API는 정답과 금액을 반환하고 UI는 지급된 것처럼 표시하며 재제출을 막는다. 로컬 PostgreSQL에서 완료 1 / 보상 청구 0을 재현했다. 현재 조회한 운영 잔액은 해당 한도에 도달하지 않았다.
2. 연습 모드에서 완료 기록 저장 후 잔액 저장이 실패하면 완료만 남고 UI 재시도가 차단된다. 운영 공유 DB 경로와 구분해야 한다.
3. 응답 확인이 끝나지 않은 경우 요청 ID는 보존되지만 학생 안내가 안전한 재시도 방법을 설명하지 않는다.
4. 과거 주별 지급 키와 날짜별 완료가 함께 남는 경우 감사가 별도 지급으로 판단할 가능성이 있다. 코드 호환성 공백이며 현재 운영에서 해당 조합은 확인하지 않았다.
