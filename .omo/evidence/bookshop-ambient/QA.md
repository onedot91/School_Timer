# 책방 생활 상호작용 검증

검증일: 2026-09-05. 실제 브라우저, 개발 전용 임시 책 데이터로 검사했다. 사용자 앱에서는 최종 배치와 화면 크기만 읽기 전용으로 확인했다.

## 최종 배치

- 차 세트: 기존 등록 책상 오른쪽 상판. 별도 선반·탁자·충돌 영역 없음.
- 고양이: 중앙의 열린 바닥. 러그에는 책, 조명, 벤치, 독서 의자가 남는다.
- 벽 화분 표시와 상호작용 좌표를 공유한다. 기존10개 가구 충돌 영역과100개 슬롯 번호를 유지한다.

## 실행 결과

- `npm run lint`: 통과.
- `npm test`: 722/722 통과, 실패0. 최종 로그는 `test-results.txt`.
- `npm run build`: 통과. 최종 로그는 `build-results.txt`.
- `git diff --check`: 통과.
- 빈 방/100권 방의 모든 대상 접근 및 선택 가능성: 월드 회귀 테스트의 충돌 기반 탐색으로 검증.
- 빈 방과100권 방에서 신규7개 대상에 실제 E 입력을 전달하고 상태 변화를 확인했다. 자동화 QA의 출발 위치 선택은 방문을 초기화하며, 각 조작 자체는 실제 Game 입력/상태/렌더러를 사용한다.
- 조명 off/on, 화분 첫 물주기와 반복, 책 펼치기/덮기 및 유지되는 책갈피, 고양이1→2→3→3, 차 따르기/마시기/빈 잔 반복 확인.
- E6회 연타로 차가 한 번만 채워졌다. 마시기 도중 blur를 발생시키고 동작 시간 이상 기다려도 잔이 차 있고 drink가 유지됐으며, focus 후 빈 잔으로 완료됐다.
- 벤치의 E/Escape/이동 해제 확인. 실제 안내 버튼 클릭 후 Canvas 초점 복귀 확인. QA 영상 도구를 펼친 상태에서는 도구가 안내를 가려 첫 클릭이 영상에 전달되어, 도구를 숨긴 실제 화면에서 재검증했다.
- 책 등록/확인/받기 후 직접 걸어서 차에 접근했다. 차 안내 클릭은 “책을 먼저 꽂아 주세요”만 표시했고 Canvas 초점과 책을 유지했다. 이후 직접 중앙 책장에 걸어가51번 슬롯에 정상 배치했다.
- 등록 확인 모달 중 이동 입력에 캐릭터 좌표가 변하지 않았다.100권 방의 독서 패널과 기존 실패 게시판 열기/닫기도 확인했다.
- 차를 채운 뒤 나가기/재입장하면 모든 방문 상태가 기본값으로 돌아왔다.
- 개발 렌더러의 동작 줄이기에서 화분2개, 조명, 벤치, 책, 고양이, 따르기/마시기 모두0ms에 최종 상태/action:null 확인 (`reduced-motion-checks.json`). OS 설정 자체의 전환은 별도로 검사하지 않았다.
- 최종 사용자 화면과 QA 게임 모두1280×800, document scrollWidth1280/scrollHeight800. 잘림·겹침·불필요한 문서 스크롤 없음. 마지막 브라우저 로그에 애플리케이션 오류 없음.

## 이미지와 영상

- `before.png`: 작업 전 화면.
- `final-live.png`: 실제 앱 최종 화면. `final-room.png`: 임시 빈 책방의 최종 화면.
- `reading-full.png`, `carrying-blocked.png`: 기존 독서와 운반 제한 화면.
- 13개 시나리오 각각0/450/900ms PNG 총39개: lamp-off, lamp-on, water-west, water-east, leaves, sit, book-open, book-close, pet-first, pet-second, pet-third, pour, drink.
- `tea-gameplay.webm`: 실제 Game Canvas 녹화44.60초,624×376. 차 따르기/마시기/연타/비활성화/재개를 포함한다. 내려받은 파일을 브라우저에서 재생했고9.28초 이상 진행을 확인했다. DOM 안내와 모달·오디오는 영상에 포함되지 않는다.
- `actual-checks.json`: 실제 입력 결과. 개발 진단 출력은1초 간격이어서 일부 중간 항목에는 직전 상태/진행 동작이 함께 기록되어 있다.100권 시나리오와 초점/재입장은 Canvas DOM의 즉시 상태를 읽었다.
- `visual-review.md`: 독립 검토 PASS, 검토한 소스/이미지 SHA256 포함. 입력 검토에서 발견한 클릭 안내 초점 문제는 수정 후 위 실제 브라우저 시나리오로 재검증했다.

하드웨어 성능은 macOS 브라우저에서만 확인했다. 실제 Chromebook 기기 성능을 검증한 것은 아니다. 새 소리·이미지·라이브러리·API·DB·localStorage 계약은 추가하지 않았다.
