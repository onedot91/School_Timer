# 차 세트 이동과 출입문 재디자인

## 변경

- 붉은 테이블 책과 펼치기/덮기/책갈피 상태·렌더링·개발 메뉴 제거. 해당 기존 테스트는 제거된 행동이 노출되지 않는지 확인하는 회귀 검사로 전환했다.
- 차 세트를 독서 테이블의 붉은 책 자리로 이동했다. 파란 책·꽃병은 유지한다. 왼쪽 접근, 오른쪽 보기, 뒤집힌 주전자 손잡이/주둥이/물줄기와 손 위치를 공유한다. 지지 가구의 깊이 순서는 독서 테이블 기준이다.
- 분리된 문짝과 큰 빈 프레임 대신 남쪽 경계에 문짝·문틀·문고리를 일체화했다. 매트는 문 앞 바닥으로 분리했다. 곰의 입장 위치는 (350,306), 퇴장 판정은 문 앞 y317..322, 문 충돌은 y322부터다.
- 문 충돌 추가에 맞춰 고양이의 접근 여유를 확보했다. 북쪽 통로 검사는 새 입장 위치에서 기존 목표 y140까지 실제 이동을 검증한다.

## 검수

- 빈 mock 방에서 차 따르기 후 teaFull=true, 마시기 후 false 확인. 오른쪽 보기로 동작하며 반복 따르기 중 일시 정지 화면을 직접 확인했다.
- 100권 mock 방에서도 같은 따르기·마시기 왕복 확인. 붉은 책 안내 대신 E 차 따르기가 표시된다.
- 문으로 아래 이동하면 (350,317.67)에서 확인창이 열린다. 취소 전후 위치 동일, Canvas 초점 복귀. 다시 아래 입력 후 확인하면 게임을 나간다.
