# 책장 수용량과 직원 주변 배치

- 네 책장의 슬롯 ID0..99와 기존 행·열을 유지했다. 6열 책장은59px,10열 책장은85px로 줄였다.
- 전체 방은 각 줄의 책등을4..7px 범위에서 페이지 수에 비례해 배분한다. 빈 슬롯도 자리를 유지하며 각 줄의 좌우 끝과1px 간격을 맞춘다. 클릭·배치·실제 책 그림이 동일 슬롯 폭을 사용한다. 작은 방의 기존 폭 규칙은 유지한다.
- 중앙 책장은(150,138),85×62로 이동했다. 직원 표시 영역까지50px 여유를 확보하고 표시/충돌/접근 좌표를 함께 변경했다.
- 넓어진 공간에서 고양이가 양쪽 끝에서는 쓰다듬을 수 있지만 경로 중간에서 접근이 막히는 회귀를 발견했다. 경로의 중간 접근성도 확인하도록 수정하고 기존 모든 경로 검사 통과.

## 확인

- 전부 얇은 책, 전부 두꺼운 책, 혼합 책의0/1/99/100권 조합에서 정수4..7px,1px 간격, 좌우 끝 채움, 재계산·입력 순서 독립성, 실제 그림과 슬롯 일치를 자동 검증했다.
- 빈 방/100권 방의 모든 시설 접근, 중앙 책장과 직원 사이 이동, 두 대상의 별도 선택, 책100슬롯 유지 검사 통과.
- 실제 브라우저100권 방의 모든 책장 줄이 끝까지 채워지는 화면 확인. 중앙 책장의51..70번 슬롯을 열고70번째 책 상세를 확인했다.
- 중앙 책장 아래에서 직원 위 통로를 이동했다. 빈 mock 방에서는 직원에게 책을 받은 뒤 실제 이동으로 새 중앙 책장까지 운반하여51번에 배치했다. 게임 상태1권, 운반 종료, 모달 닫힘 확인.
- 실제 사용자 책방1280×800에서 배치 확인, document scrollWidth1280/scrollHeight800. 개발 브라우저 콘솔 error/warn 없음. 임시 viewport 설정 복원.
