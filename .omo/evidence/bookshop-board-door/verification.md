# 게시판·문·매트 최종 검수

## 최종 반영
- 게시판: 4px 목재 테두리, 저대비 1px 코르크 질감, 실제 게시글 0~24개 메모. 긴 가로선과 상단 장식 제거.
- 문: 문짝·문틀·문고리만 캐릭터 다음에 55%로 한 번 합성. 사용자 추가 요청에 따라 양옆 벽 제거. 기존 문 영역·충돌·퇴장 판정 유지.
- 매트: 42×14px의 채워진 민트 직조 무늬, 얇은 가장자리와 접촉 그림자. 문 1px 앞에 배치. 굵은 내부 테두리와 술 제거.

## 검증
- npm test: 769개 통과. npm run lint, npm run build, git diff --check 통과.
- 렌더링 회귀: 메모 0·1·24개의 프레임 내 배치, 코르크 질감, 출입문 레이어 외부 벽 없음, 불투명도 0.55 단일 합성, 레이어 재사용 및 정리 검사.
- 실제 mock 게임: 출입문 앞 정지 및 옆 이동 시 모달 없음. 아래로 이동 시 퇴장 모달. 취소 시 Canvas 초점 복귀.
- 등록대에서 책을 받은 뒤 문까지 직접 이동. 운반 중 경고가 표시되고 취소 시 책·초점 유지. 다시 아래로 이동 후 확인 시 검수 시작 화면으로 정상 퇴장.
- 고양이 자율 이동 관찰 및 기존 경로·충돌 회귀 테스트 통과.
- 최종 사용자 화면 innerWidth=1280, innerHeight=800, scrollWidth=1280, scrollHeight=800. 잘림·문서 스크롤 없음. 두 브라우저 탭 오류/경고 로그 없음. 임시 viewport 초기화.
