# 전국 책방 챌린지 구현·검증 기록

## 구현 범위

- 17개 학교의 공통 월별 시드, 0~100권 순위, 대구장동초등학교 실제 확정 배치 집계.
- 수업시간 지연 반응·자연 성장·상대적 상한·시간당 제한·교사 속도/정지/수동 조정.
- 기존 shared-settings API 확장, 시즌 ID 배치 검증, 원자적 월별 보관/책장 초기화 SQL.
- 격리된 연습 모드, 공유 상태 보호, 읽기 전용 모드의 무변경 조회.
- 도서관 트로피 순위판, 월별 지난 기록, 기존 설정창의 교사 조정 UI.

## 검증 중 수정한 결함

- 같은 밀리초 저장과 서버 투영 시각의 차이로 발생하던 초기 조회 실패.
- 월 변경 때 교사의 일시정지/성장 속도가 초기화되던 문제.
- 반응 난수에 책 ID를 통해 학생 번호가 간접 반영되던 문제.
- 교사가 속도만 바꿀 때 예전 화면의 상대 점수까지 덮어쓰던 문제.
- 지난 기록의 선택 가능한 월 목록 유실.
- 교사 확인 버튼 제거 후 포커스가 페이지 본문으로 이탈해 Escape가 작동하지 않던 문제.
- 200% 글자 확대에서 숫자 100과 순위 머리글이 잘리거나 줄바꿈되던 문제.

## 운영 적용 경계

`supabase/library_competition.sql`은 준비했지만 운영 DB에는 적용하지 않았다. PostgreSQL 실행 환경이 없어 PL/pgSQL 실행, 실제 트랜잭션 잠금·롤백·권한 동작은 아직 엔진 수준으로 검증하지 못했다. HTTP fixture/코드 리뷰는 그 검증을 대신하지 않는다.

운영 적용 전 별도 승인과 폐기 가능한 PostgreSQL/Supabase 환경에서 SQL 실행 검증이 필요하다. 확인 항목은 23명 동시 최초 생성, 동일 슬롯 경쟁, 월 변경 중 실패 롤백, 단 한 번 보관, 학생 역할의 RPC/보관 테이블 접근 거부, 일반 설정 쓰기의 경쟁 상태 보호다. SQL을 적용하지 않은 공유 환경에서는 새 챌린지만 이용 불가 상태이며 기존 도서관은 유지한다.

Git 커밋/푸시 및 사용자 localhost:3000 서버 변경은 하지 않았다. 기존 작업 변경사항을 보존했다.
