# 연간 ㄱㄴㄷ 카탈로그 v1

- 적용 시작: 2026-09-07, 한국 시간. 월~금 한 개씩, 공휴일·방학 포함.
- 어휘 400개: 학습 100 / 자연과학 100 / 사회문화 100 / 생활과 마음 100.
- 주제 300개: 학교 100 / 자연 100 / 생활 100. 각 주제의 `examples`는 ㄱ~ㅎ 순서 14개 내부 검수 답안이며 학생 화면에 표시하지 않는다.
- 원문 참고: `2023 초등 어휘싹(3학년).pdf` 핵심 60단원. `source: 어휘싹3:N`의 N은 인쇄 쪽수다. 단원 뜻을 확인한 뒤 현재 빈칸 형식에 맞춰 일부 용언은 명사형으로 바꾸고 예문은 새로 작성했다. 인쇄 61쪽 어휘는 **닳다**다.
- `grade`는 앱 문항의 집필 난이도(3~6학년), `family`는 배정 시 연속 출제를 피할 의미 분류다. 공식 교육과정 인증이나 학생별 수준 평가를 뜻하지 않는다.

## 배정과 호환성

`classwordSchedule.ts`의 고정 시드로 의미 분류별 목록을 섞고 분산해 한 번 정한 순서를 순환한다. 학년·연도가 바뀌어도 다시 섞지 않는다. 각 연속 262평일에는 어휘와 주제가 반복되지 않는다. 자동 주제는 저장하지 않으며 날짜의 비어 있지 않은 교사 저장 주제가 우선한다. 빈 주제로 저장하면 자동으로 복귀한다.

기존 시작일 이전 퀴즈는 7문항의 원래 ID와 날짜 계산을 유지한다. 학생 주말 조회는 금요일로 연결하지만 원래 주말 기록은 삭제하지 않으며 교사 날짜별 조회로 유지한다. 주말 학생 등록·수정·삭제·퀴즈·보상 요청은 서버와 mock 경로에서 막는다.

**게시된 v1의 배열·ID·분류·시드를 수정해 과거 배정을 바꾸지 않는다.** 후속 확장은 v2 데이터와 명시적 적용일을 추가하고 날짜별 버전을 선택한다. `classwordAnnual.test.ts`의 ID 순서 해시는 실수로 v1 배정이 바뀌는 것을 감지한다. 문제 ID는 정답의 고정 해시로 생성되며 정답 자체를 포함하지 않는다.

## 검수

전체 뜻·800개 예문을 읽고 초성 충돌 및 어근 중복을 대조했다. 300개 주제는 교차 검토해 겹치는 활동을 교체했다. 자동 테스트는 문항·주제 수, 고유 ID/정답, 초성, 예문 조합·길이, 4,200개 주제 예시의 기존 입력 규칙, 의미 분류 순환 경계와 5년간 모든 262평일 구간을 검사한다. 의미 적합성은 사람이 별도로 검토해야 하며 형식 검사 통과만으로 보장되지 않는다.

검증 명령: `npm run lint`, `npm test`, `npm run build`.
개발 전용 실제 UI 검증: `/dev/classword-review.html` (DEV+mock에서만 사용, 문서 전용 메모리 저장소와 가상 날짜 사용).
