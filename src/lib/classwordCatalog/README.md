# 연간 ㄱㄴㄷ 카탈로그

## 현재 어휘: 초3~4 개정판 v2

2026-09-06 요청에 따라 첫 자동 배정일인 **2026-09-07부터 v2**를 사용한다. 기존 400개 중 어려운 낱말 114개를 교체하고, 41개는 뜻과 두 예문을 쉽게 다시 썼다. 나머지 245개 및 PDF 핵심 어휘 60개는 유지한다. 현재 집필 난이도는 3학년 158개·4학년 242개이며, 모든 뜻과 예문은 각각 50자 이내다. 학년 표기는 공식 교육과정 인증이 아닌 앱의 집필·검수 기준이다.

수정 내역은 `vocabularyGrade34.ts`, 현재 배정용 배열은 `classwordVocabularyGrade34.ts`에서 관리한다. v1 원본은 수정하지 않았고 개정 문항 ID는 `annual-v2-`로 구분한다. 시작일 이전의 7문항 배정, 완료·보상 기록, 교사 직접 설정은 변경하지 않는다. 어휘의 평일 순환·주말 읽기 전용 규칙도 그대로다. 주제는 아래 선별 기준을 따른다.

v2 역시 공개 뒤에는 배열·ID·분류·시드를 바꾸지 않고 다음 버전과 적용일을 추가한다. `classwordGrade34.test.ts`가 학년 범위·고유 정답·예문·초성·PDF 어휘 보존·배정 순서를 검사하며, 기존 연간 테스트가 연속 262평일 무중복과 날짜 경계를 검사한다.

## 현재 주제: 적합성을 우선한 범주형 주제 v2

2026-09-07부터 `topicsSchoolV2.ts`, `topicsNatureV2.ts`, `topicsLifeV2.ts`에서 선별한 주제 165개(학교 33·자연 71·생활 61)를 사용한다. 특정 행동이나 절차 대신 ‘학용품과 준비물’, ‘동물’, ‘둥근 것’, ‘여러 가지 음식’처럼 학생이 다양한 낱말을 떠올릴 수 있는 범주로 구성한다. 이름만 다른 유사 주제와 초성만 맞춘 억지 예시는 검수 대상이다. 14개 초성 예시는 내부 검수용이며 학생에게 정답 목록으로 제공하지 않는다.

자동 배정, 경과 주제 목록, 교사의 무작위 추천은 같은 개정판을 사용한다. 사용자의 후속 요청에 따라 300개 및 주제의 1년 무중복 조건을 해제했다. 남은 주제를 평일마다 한 개씩 모두 사용한 뒤 같은 순서로 다시 순환하며, 교사가 직접 저장한 주제와 학생의 기존 낱말은 수정하지 않는다. 원본 주제 v1은 보존하고 `classwordTopics.ts`에서 적용일에 따라 카탈로그를 선택한다. `classwordBroadTopics.test.ts`가 개정판의 수·중복·초성 예시·적용일을, 기존 연간 테스트가 실제 배정의 무중복을 검사한다.

선별 기준: 낱말이 속하는 범주를 학생이 쉽게 이해할 수 있어야 한다. ‘게임 속 세상’, ‘상상 속 세상’, ‘꿈과 목표’, ‘주인공의 성격과 태도’처럼 모호한 주제, 억지 연상이 필요한 주제, 답이 지나치게 겹치는 주제 등 135개를 제외했다. 빈자리를 채우기 위한 대체 주제는 추가하지 않는다. 남은 항목의 ID는 재번호를 붙이지 않는다.

## 보존된 초기 어휘 v1 및 주제 v1

- 적용 시작: 2026-09-07, 한국 시간. 월~금 한 개씩, 공휴일·방학 포함.
- 어휘 400개: 학습 100 / 자연과학 100 / 사회문화 100 / 생활과 마음 100.
- 주제 300개: 학교 100 / 자연 100 / 생활 100. 각 주제의 `examples`는 ㄱ~ㅎ 순서 14개 내부 검수 답안이며 학생 화면에 표시하지 않는다.
- 원문 참고: `2023 초등 어휘싹(3학년).pdf` 핵심 60단원. `source: 어휘싹3:N`의 N은 인쇄 쪽수다. 단원 뜻을 확인한 뒤 현재 빈칸 형식에 맞춰 일부 용언은 명사형으로 바꾸고 예문은 새로 작성했다. 인쇄 61쪽 어휘는 **닳다**다.
- 보존된 초기 어휘의 `grade`는 당시 집필 난이도(3~6학년), `family`는 배정 시 연속 출제를 피할 의미 분류다. 현재 학생용 어휘는 위의 v2(3~4학년)를 사용한다.

## 배정과 호환성

`classwordSchedule.ts`의 고정 시드로 의미 분류별 목록을 섞고 분산해 한 번 정한 순서를 순환한다. 학년·연도가 바뀌어도 다시 섞지 않는다. 어휘는 각 연속 262평일 동안 반복되지 않는다. 주제는 선별된 목록을 한 바퀴 다 쓰기 전까지 반복되지 않는다. 자동 주제는 저장하지 않으며 날짜의 비어 있지 않은 교사 저장 주제가 우선한다. 빈 주제로 저장하면 자동으로 복귀한다.

기존 시작일 이전 퀴즈는 7문항의 원래 ID와 날짜 계산을 유지한다. 학생 주말 조회는 금요일로 연결하지만 원래 주말 기록은 삭제하지 않으며 교사 날짜별 조회로 유지한다. 주말 학생 등록·수정·삭제·퀴즈·보상 요청은 서버와 mock 경로에서 막는다.

**게시된 v1의 배열·ID·분류·시드를 수정해 과거 배정을 바꾸지 않는다.** 후속 확장은 v2 데이터와 명시적 적용일을 추가하고 날짜별 버전을 선택한다. `classwordAnnual.test.ts`의 ID 순서 해시는 실수로 v1 배정이 바뀌는 것을 감지한다. 문제 ID는 정답의 고정 해시로 생성되며 정답 자체를 포함하지 않는다.
